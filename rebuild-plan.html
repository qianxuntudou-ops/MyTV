MyTV CCTV Only Android 7+

重构计划

目标是把当前工程重构为一个只看央视直播的原生 TV 播放器，去掉 WebView 播放路径、第三方通用源兼容包袱和历史配置页面。

1. 产品目标

  • 只保留央视直播频道。
  • 开机进入播放器，选频道即播。
  • 使用原生播放器链路，优先走硬件解码。
  • 自动全屏，遥控器操作优先。
  • 支持画质切换。
  • 最低兼容 Android 7.0，建议 minSdk = 24。

2. 技术栈

运行时

  • Kotlin
  • Android SDK 35
  • minSdk 24

播放

  • AndroidX Media3 ExoPlayer
  • PlayerView
  • HLS
  • 底层依赖 MediaCodec 走硬解

网络与数据

  • OkHttp
  • Gson
  • Coroutines

UI

  • XML
  • ViewBinding
  • TV 遥控器按键驱动

3. 架构方案

模块 职责
MainActivity 承载播放器、处理全屏、遥控器按键、管理 overlay 显隐。
CctvPlayerController 统一管理 ExoPlayer 生命周期、切台、切画质、错误恢复和重试。
CctvStreamResolver 请求央视直播接口，按频道和画质解析可播放的 HLS 地址。
CctvChannels 内置央视频道定义，维护频道编号、显示名称、解析所需频道标识。
ChannelOverlay 频道选择面板，TV 焦点优先。
QualityOverlay 画质选择面板，直接映射央视可用清晰度档位。
AppSettings 仅保留最少配置，例如默认频道、默认画质、是否显示时间。

4. 和现有项目的关系

结论：不删除整个仓库，但按新项目思路重建 app 业务层。

保留

  • gradle/、gradlew、gradlew.bat
  • 包名和应用基本构建骨架
  • 少量通用工具类，如果仍有价值

删除或重写

  • WebView 播放逻辑
  • 本地网页配置页和 NanoHTTPD 远程设置
  • 第三方源导入、通用 IPTV 兼容逻辑
  • 与当前目标无关的设置项、资源文件和依赖

5. 旧代码裁剪原则

  • 凡是围绕 SimpleServer、settings_web、sources、远程配置网页的代码，默认删。
  • 凡是只为 WebView 播放服务的模型、状态和 UI，默认删。
  • 凡是对“央视官方直播 + 原生 HLS 播放”无贡献的第三方依赖，默认删。
  • 保留频道列表、EPG、基础偏好存储这类还可以复用的部分，但要按新职责重写。

6. 分阶段实施

阶段 1：骨架清理

  • 恢复原生播放依赖，接入 Media3。
  • 删除 WebView 播放路径和相关资源。
  • 补齐 .gitignore，清理无关缓存和输出目录。

阶段 2：建立播放主链路

  • 实现 CctvStreamResolver。
  • 实现 CctvPlayerController。
  • 先打通 CCTV-1、CCTV-13、CCTV-5。

阶段 3：TV 交互与 UI

  • 上下切台、左右切画质、中键呼出频道列表。
  • 自动全屏、自动隐藏 overlay。
  • 保留必要的时间和错误提示。

阶段 4：稳定性与性能

  • 失败重试、超时控制、网络错误提示。
  • 优化播放器缓冲策略。
  • 验证硬解路径和多档画质切换行为。

阶段 5：收尾

  • 删除剩余旧代码和无用资源。
  • 跑 lint、assembleDebug。
  • 至少验证 Android 7、9、11 三档设备行为。

7. 风险与验证

  • 最高风险：央视接口参数和签名策略可能会变化。
  • 次级风险：不同频道和不同档位未必都长期开放。
  • 验证路径：优先用 3 个频道验证解析、播放、切档、重试，再扩展到全量 CCTV。

8. 本次重构明确不做

  • 不做第三方直播源聚合。
  • 不做网页播放器兜底主路径。
  • 不做通用 IPTV 平台。
  • 不优先保留当前的远程网页设置能力。

结论：这是一次“保留工程骨架、重写 app 业务层”的重构，不是继续修补旧链路。
